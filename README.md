## 5. Woodcutter Script -lisäosan käyttö

1. Kirjaudu sisään hahmollasi ja siirry valitsemasi puun alueelle (kirves kädessä tai repussa):
   - **Oak**: Varrock West (Varrockin länsipankin viereiset tammet)
   - **Yew**: Woodcutting Guild (Pankkiarkun viereiset marjakuuset)
   - **Magic**: Woodcutting Guild (Pankkiarkun viereiset taikapuut)
2. Avaa RuneLiten oikean reunan jakoavain-ikoni (**Configuration / Asetukset**).
3. Etsi hakusanalla: `Woodcutter Script`.
4. Ota lisäosa käyttöön kytkimestä.
5. Avaa lisäosan asetukset (ratas-ikoni):
   - **Start Script** -> Laita päälle (`ON`), kun haluat aloittaa hakkauksen ja pankituksen.
   - **Tree and Location** -> Valitse kohde (`Oak - Varrock West`, `Yew - Woodcutting Guild` tai `Magic - Woodcutting Guild`).
6. Ruudun vasempaan yläkulmaan ilmestyy tilapaneeli (aivan kuten Motherlode Mine -skriptissä), joka näyttää reaaliajassa:
   - **Status**: RUNNING / STOPPED
   - **State**: Chopping tree / Walking to bank / Banking / Waiting for tree spawn
   - **Target Tree**: Valittu puu ja sijainti
   - **Inventory**: Halkojen määrä repussa (`x / 28`)
   - **Logs Cut**: Istunnon aikana kaadetut halot
   - **XP Gained**: Saadut kokemuspisteet
   - **Uptime**: Kulunut aika (`HH:mm:ss`)
